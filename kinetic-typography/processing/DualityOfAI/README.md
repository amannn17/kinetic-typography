# Processing sketch

Add the three sketch files here:

- `DualityOfAI.pde`: setup, draw loop and all input-to-output mappings
- `SensorInput.pde`: OSC/ZigSim handling, thread-safe, normalised values
- `GlitchLetter.pde`: letter buffer, tiling, sine wave and 3D rotation

Processing requires the main file to have the same name as its folder. If you rename the sketch (for example to `KineticTypography.pde`), rename this folder to match and update the main README.

Delete this file once the sketch files are in place.
